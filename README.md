# Resume

Rodrigo Alvarez's resume, written in LaTeX.

- [`master.tex`](master.tex) — the source of truth. Edit this file to make changes.
- [`master.pdf`](master.pdf) — compiled PDF, auto-generated on every push.
- [`master.md`](master.md) — plain-Markdown copy, auto-generated on every push.

`master.pdf` and `master.md` are regenerated automatically by [GitHub Actions](.github/workflows/build.yml) whenever `master.tex` changes on `main` — don't edit them by hand, your changes will be overwritten.
